  • Create containers # pct create 200 local:vztmpl/fedora-44-cloud_amd64.tar.xz \ -cores number_of_cores \ -memory amount_of_ram_in_mb \ -swap amount_of_ram_in_mb \ -ostype system_name \ -storage storage \ -rootfs volume=local-lvm:20 \ -net0 name=interface_name,bridge=bridge_name,firewall=1or0,ip=dhcp \ -password password \ -unprivileged 0 \ -features nesting=1 \ -start 1

    local:vztmpl is a shortcut for /var/lib/vz/template/cache/ local stands for /var/lib/vz/ vztmpl stands for ..../template/cache/

    -rootfs volume=local-lvm:20 Sets the root file system
