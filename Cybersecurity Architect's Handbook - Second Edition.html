Access Control

Access control policies: Define high level requirements, how access is managed and who can access info under certaim circunstances. Least Privilege: grants the minimum necessary privileges, thus reducing unathorized access risks. Need-to-know: Access to information is strictly restricted to certain roles. Access control model: models bridge policies and mechanisms through formal representation of the security policy enforced by the system. DAC (Discretionary Acess Control): access rights are controlled freely by resource owners MAC (Mandatory Access Control): strict access is enforced by security classifications and labels RBAC (Role-based Access Control): Predefined roles set the permissions accordingly with job functions, which simplifies administration.

Notes from Cybersecurity Architect's Handbook - Second Edition by Lester Nichols
